# 口播剪辑工作台 · talking-edit

给它已录好的真人口播视频（可附SRT、文稿和图片），Agent负责剪辑策划与执行，本地工作台负责导入、选择风格、字幕修订、审看和交付。随包提供静态页面，用户无需启动前端开发环境。当前版本 **v0.2.0，Windows源码试用版**。

## 安装与开始

把下面这段话发给Codex等支持Skill和本地命令的Agent：

> 请安装 https://github.com/zhangyanhua0913/talking-edit/tree/main/skills/talking-edit ，读取SKILL.md，运行doctor并准备缺少的依赖。然后使用talking-edit剪辑我指定的口播视频，打开本地工作台，让我选择风格与语速。先使用免费本地流程，不调用付费接口。

复现此版本可用 [v0.2.0固定安装地址](https://github.com/zhangyanhua0913/talking-edit/tree/v0.2.0/skills/talking-edit)。已有同名Skill时先保留包外项目，更新整个Skill目录，重新开始Agent会话。不要只下载SKILL.md；脚本、页面、模板、许可和references均需安装。

## 工作流程

导入视频 → 选择步骤Skill与语速 → 本地转写或复用SRT → 改字幕、审看剪切候选 → 确认粗剪 → 选择动态包装 → 审看关键帧 → 本地合成 → 听看与局部修改 → 交付MP4、SRT、映射清单和可恢复项目；使用动画时保留对应工程。

页面包含项目素材、流程配置、字幕粗剪、动态包装、关键帧成片、任务交付及批量处理。默认手动确认，固定底部确认栏显示当前阶段；关闭页面不算确认。项目可中断恢复，旧页面不能覆盖新版，旧成片保留并标记。

## 可选制作方式

| 选择 | 能做什么 | 自动化范围 |
|---|---|---|
| 无动态包装 | 真人画面、字幕、同步剪切与变速 | 可选本地全自动 |
| 暗金科技 | 标题、流程、对照等动态组件及章节层 | 自动模式目前仅按字幕生成标题动画；复杂图解由Agent制作 |
| 资料讲解与人物同屏 | 人物全景、侧窗、小圆窗，结合流程、关系、对照或用户资料 | 独立风格模板，由Agent按内容编排；暂不支持批次全自动 |
| Remotion自由创意 | 按内容设计画面与动作 | 需安装Remotion插件，由Agent制作 |
| FredTalk动态包装 | 检索公开组件，核验源码、关键帧后制作 | 固定上游依赖，由Agent制作；部分组件需另备合法素材 |

内置暗金及资料讲解模板随包分发，不要求另装特定版本的Remotion插件。新增第三方Skill须由Agent审阅、编写并验证适配器，不能把任意仓库链接直接当可执行能力。

## 批量与全自动

在“批量处理”一次选多个视频，统一选择风格和语速，每条视频创建独立项目。默认在同一个主项目内**一个接一个执行**，电脑配置较低也可排队；不同主项目之间尚无全局资源锁，请勿同时启动多个主项目队列。

显式勾选全自动后支持：本地Whisper → 保留原内容 → 无包装或暗金标题模板 → 合成。不会自动删除口误或停顿，不包含复杂语义图解、资料搜集、付费任务或最终质量认可。单视频也可放入自动批次。自动结果仍待用户听看；未勾选时按阶段手动确认。

## 环境与数据

- 已验证Windows，Python 3.11+；本地faster-whisper建议由Agent使用Python 3.12创建隔离环境，默认small、多语言、CPU/int8，首次下载模型。
- 需FFmpeg/ffprobe；动画另需Node.js/npm、锁定依赖及Remotion的浏览器。由Agent检查并准备，不更改其他软件环境。
- 本地剪切/导出当前通过包外固定FredTalk执行层，首次需准备它，即使选择无动态包装。模型、依赖和项目不随包预装。
- 默认原画幅、原速、不加BGM，导出最高1080p/30fps；速度可选1至1.5倍。资料讲解组合模板默认720p横屏，其他画幅需Agent调整核验。
- 凭据保存在本机Windows DPAPI；运行项目、媒体、依赖和模型均位于Skill包外。页面仅监听回环地址，临时会话链接不要转发给他人。

云端千问当前缺少可核实的Token费用上界，**新提交关闭**，不静默上传或改用其他模型。源码本地执行不调用付费模型，但依赖下载需要网络、存储和本机算力；第三方依赖、素材和软件遵守各自许可。

实际完成过真人口播、1.3倍合成、暗金整片及独立资料讲解同屏审看片；自动模板链另以合成素材验证，不等于所有真人批量场景已验收。技术检查、实际听看、用户认可分别记录。macOS/Linux、任意Agent、多机位、数字人、剪映草稿、自动发布及任意Skill即装即用不作首版承诺。
