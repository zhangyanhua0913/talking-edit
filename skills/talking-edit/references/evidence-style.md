# 资料讲解与人物同屏

这是基于实际参考片拆解形成的 Agent 制作方式，适用于有论证、案例、产品演示、数据和行动建议的口播。使用随包Remotion组合模板，有插件时可参考其制作指引，无需特定插件版本。不是只增加标题密度，也不保证任意口播自动适配。

## 先规划画面在讲述中的作用

给每段写清：源时间、台词、叙事目的、画面主体、资料来源、显示区域、动画动作、返回人物的时机。优先顺序为准确解释内容、让观众看清、再增加运动。连续多个场景可共享同一时间轴或关系图，逐步加入节点；避免每句话换一个互不相干的卡片。

| 语义任务 | 构图 | 动作 |
|---|---|---|
| 开场提问、立场、转折 | 人物为主 | 一次关键词出现或少量侧边标注；不要全片压暗人脸 |
| 引用一段材料 | 资料主画面＋人物小窗 | 原文截图→裁切放大→匹配旁白划线；保留标题、来源和上下文 |
| 两种说法、方法或状态 | 人物＋双列 | 对齐维度后逐项显示；不随意编造“正确答案” |
| 几个日期的连续事件 | 可持续展开的时间轴 | 日期节点出现、相应截图进入、节点连线，最后收束到共同观点 |
| 数值、比例、规模 | 人物＋有来源图表 | 先单位和基准，再显示数值；柱高按真实比例，不用装饰进度条冒充测量 |
| 一组证据推导结论 | 证据画廊→人物回归 | 材料缩成缩略图、连线收束，强调结论但保留限定条件 |
| 具体行动 | 人物＋清单/操作状态 | 一次展示一项；对应口播逐项勾选，收尾回人物 |

## 可复用的画面系统

深灰背景、白正文、黄强调；青色/红色只用于区分对象或状态。章节导航可常驻顶部，当前章节填色或进度推进，内容区和底部字幕区独立。字幕保持整句或短语可读，只将少量关键词染黄。没有字级对齐时不要称为逐字同步。常驻条不宜抢人物和主要证据的注意力。图表需标清示意/来源，不复制参考片的账户、头像、水印或对外事实。

人物布局在全景、左侧竖窗、角落小窗之间按信息量切换；裁切前核查人物头部与手势安全范围。随包独立组合模板 `templates/evidence-motion/src/Evidence.tsx` 已实现三种人物布局、章节导航、底部短语字幕、流程、对照、复用、关系和引用面板，以及可选本期图片。模板独立实现，不导入暗金或FredTalk组件。复制模板到包外锁定依赖工程，按 `Props` 提供本期source/scenes/cues/chapters，时间使用剪切后的成片坐标；source为无烧录字幕的视频，人物和字幕已由模板统一组合，音轨另按同一时序混合。模板默认1280×720、30fps，需要其他画幅时先改布局并核验。整片组合产物不是透明包装片段，不能用attach-scene重复叠加人物、字幕和声音；按独立审看片记录项目基础版本、素材hash与实际输出，不能冒充原项目正式导出。

节奏从句子论点及动作持续时间出发。背景只做低强度纹理；对关键转折优先做构图变化而非满屏粒子。单场景的对象依次进入、解释、停留、退出；停留需让人读懂。画面总览及每段进入/中间/收尾均检查，避免白块、遮住来源、字体太小和图表失真。

声音：保留自然表达；先检查语句接缝和音画时钟，再决定语速、配乐和音效。仅凭最终混音不能确认源片是否降噪、加速、压缩或配何音乐。BGM和音效按用户选择及实际素材执行，切勿为模仿参考片自行找私人音乐。

## 输出和验证

先输出分段表及资料清单，再做真实关键帧和短样片，按当前项目确认范围继续合成。无资料时使用人物或清晰标注的示意；不知道的数据保持未知。引用内容是否真实，需要另外查原始来源，不能以参考视频里的截图当作事实验证。提供整片MP4、SRT、映射和工程，技术检查、实际听看、用户确认分别记录。

首版此选项仅为Agent创作适配，不支持批次全自动。自动标题模板不能被称为已具备本方案的资料检索、语义论证和复杂同屏制作。
