# 暗金科技动态包装

选择 `remotion-gold` 后，按 `remotion-workflow.md` 的时间映射与采纳协议工作；此内置模板无需另装特定Remotion插件，有插件时可参考其制作指引。此能力由 Agent 创作和编排，不自动识别内容、不保证逐字时码。模板位于 `templates/gold-motion`，把它复制到项目的包外工作目录；在副本中按锁定文件安装 Node 依赖，勿在 Skill 安装目录或参考工程中安装。用户已提供本机 Remotion 时仍须核实版本、安装状态与来源。

模板 `src/Gold.tsx` 提供暗金网格、呼吸光斑、动态标题和对比、流程、关系、条形等视觉组件，以及可配置的进度、章节和字幕层；`src/index.tsx` 是无真实信息的可运行示例。根据当前剪辑的源→输出映射、字幕及用户选择，重新组织场景和素材，调整节奏、画幅、安全区及人物出镜；不要将示例内容或其他视频的场景时间当作当前文案。进度、章节、配乐及用户品牌需单独明确；不可默认写入其他人的水印或承诺事实、收益和数值。

按当前项目流程先提交逐段包装方案，再制作独立无音轨、无烧录字幕的片段，使用 `render-scene` 与 `attach-scene` 并审看关键帧，最终通过项目 `step render` 将视频、字幕和音频合成。模板动画由 Agent 按所需片段时长及语义调整；模板示例只是启动点，不是完整视频自动生成器。已有整片和音轨的参考预览不能作为叠层片段。

若只有句级 SRT，句内逐字高亮只能标记为估算，不能说是精确字级识别；用户确认后仍须抽查接缝、字幕、音画和视觉效果。渲染可能耗时，未完成或未听看的状态必须如实报告。此风格不修改原项目与他人参考工程，老版本保留。

批次显式选择全自动时，由 auto_gold.py 使用可执行的本地模板。当前仅生成基于字幕的标题动画，按间隔与剪切边界选择片段，过滤短语气词；不冒称语义推理或提供与Agent手工设计同等的20种场景。自动任务在其授权范围内记录确认，产物仍需用户听看。自由创作场景不由此模板覆盖。
