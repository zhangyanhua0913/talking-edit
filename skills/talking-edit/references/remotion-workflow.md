# Remotion 插件包装适配

由 Agent 调用已安装的 remotion:remotion-best-practices，并按需读取 remotion-create、remotion-markup 和 remotion-render。工作台只保存选择与交互，不自行启动或冒充 Agent。以当前确认的剪辑、字幕和源→输出映射作为依据，明确时间、字幕安全区、人物保留比例和用户反馈；提供几种区别明显的方案供试听审看。可使用本人素材或用户提供且有权使用的图片、图形；不要把缺少素材的说明性动画说成真实现场画面。

创建包外、锁定依赖的Remotion工程，启动 Studio 预览，制作短样片和真实关键帧；`render-scene` / `attach-scene` 保留工程和片段，按项目revision确认后再合成。任何外部生成、上传或付费仍需各自明确授权；不默认购买素材。用户要求对照时优先试局部动效、文字信息可视化和全屏解释，而不是机械减少人物。不能将技术通过等同于用户视觉认可。

导入到现有源时钟的正式动画片段应不含已烧录字幕和重复声音；带成片画面及音轨的对比样片仅用于审看，不能原样当正式覆盖素材，否则会重复字幕或音轨。正式合成以项目当前选定语速和有效确认范围为准，若用户单独加速过外部MP4，先核对项目速度而不是把外部文件误认成项目当前版本。
